# 海报与视觉设计

读取 `upstream/canvas-design/SKILL.md`；字体资源位于同目录的 `canvas-fonts/`，每个字体族随附原始许可。官方原文与资源未修改，完整来源和固定版本见 `upstream-sources.json`。本入口是 RunTeams 编写的使用适配。

根据本次用户的主题、受众、尺寸、必须显示的文案和已有品牌选择视觉表达，生成可打开的 PNG 或 PDF。用户的文字与品牌约束优先；上游假定“用户已经要求更完美”的句子不是本次真实反馈，固定哲学段落和90%图形比例也不能成为覆盖实际需求的硬规则。创作说明只在有用或用户要求时交付，默认先呈现最终作品。

采用当前官方 Runtime 可用的文件、绘图与预览能力；有可用图像生成能力时按需使用，没有时可用代码生成原创视觉，不能宣称调用了不存在的工具。所需 Python/绘图库或字体在任务环境准备，不修改用户全局环境。

字体按所需文字覆盖选择。随附字体不代表支持中文；中文海报必须核对字形覆盖，采用可用且许可适合的中文字体，缺少时明确报告，不能输出方框或悄悄改成英文。不改写或移除字体许可及保留名称，不为字体建议自动购买或使用未经允许的素材。

交付可编辑源文件时，一并交付它重新打开或导出所需的字体、许可和素材：可登记包含完整相对目录的源文件包，或在许可允许时嵌入资源并附许可。文件留在工作区不等于用户已收到；必须核对实际登记的交付资源。将交付版本复制到没有工作区素材的独立目录重新打开、导出，与最终图像比较，避免源文件下载后缺字或排版变化。

把生成文件实际渲染并目视检查：尺寸正确、重要文案完整、无裁切/重叠/缺字、视觉层级清楚。发现问题修正后再交付。工作合同需要的文件登记为可打开的成果，源代码和验证信息放在次级资源，不用文件存在代替视觉验收。

## 正式工作与代表样例

工作范围和完成标准见 [runteams.json](runteams.json)，代表样例见 [references/work-examples.json](references/work-examples.json)。只把实际执行且读回核对的结果称为工作完成；结构、健康检查和模拟分别记录。
