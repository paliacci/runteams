# 前端设计与实现

先读取 `upstream/frontend-design/SKILL.md`。原文和许可证保持不变，来源与固定版本见 `upstream-sources.json`；以下为 RunTeams 独立编写的适配说明。

根据真实使用目标、内容和已有品牌确定设计方向，再实现可运行页面。先观察已有页面和设计系统；已有确认的设计稿、主题变量或组件时以它们为依据，上游鼓励创造新风格和调色板的建议不能覆盖用户的确认稿。修改 RunTeams 界面时采用本项目设计守护、全局语义颜色和唯一正式 Figma 库。

完成后启动实际页面，操作主要路径，检查桌面及窄屏、键盘焦点、文字可读性、加载和失败恢复，并截图检查布局。复用当前原生浏览器或测试能力；需要建立项目副本、准备环境或登记缺陷时使用现有项目运行和缺陷分析方法，不另造业务状态或测试结果。

当前渠道没有可调用的浏览器界面时，优先采用官方 Playwright CLI 或 Playwright 的成熟交互接口，并在任务内准备依赖。浏览器未完成加载、键盘事件没有正确发送或检查脚本出错时，先核实测试方法，再判定页面缺陷；保留失败记录并真实重跑，不能把截图生成当成表单通过。浏览器进程与临时配置只清理本任务创建的部分。

截图应来自字体加载完成、视口与布局稳定后的真实画面；调整视口后检查实际截图，避免保留尚未重绘的残影、重复片段或裁切。若截图与 DOM 几何矛盾，重新打开该视口核实，不能只根据无溢出的数值断言视觉通过。

交付可运行代码及必要的使用说明，保留截图和实际验证记录。没有真实业务接口的交互如使用样例，必须标明，不能把静态按钮当已完成服务，也不自动部署或购买服务。
