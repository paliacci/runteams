# Contributing

Report reproducible issues and propose changes through this repository. Keep
account credentials, personal documents, model keys and local databases out of
issues, commits and logs. For private security reports, use the repository's
private vulnerability reporting feature.

By intentionally submitting code for inclusion, you confirm that you have the
right to submit it and identify all third-party material and licenses. A pull
request alone is not treated as a copyright assignment or permission to relicense
third-party code. Contributions requiring additional licensing rights for the
official distribution will only be merged after a separate explicit agreement.
Do not submit code whose license conflicts with the intended component license.

Use Python 3.12 and the canonical commands in README.md. Keep local business
behavior in runteams_core, developer tooling in runteams_core.devtools and public
SDK code in sdk. Official account, marketplace, subscription and cloud features
belong in the private official repository. Do not add old-path forwarding modules.
