常见问题

还有点疑问？

要不要另买模型密钥？+
不用。RunTeams 复用你已经登录的 Claude Code / Codex CLI，模型费用走你自己的账号，我们不加价倒卖 Token。
任务在哪里运行？+
全部在你自己的电脑上。中转服务器只负责把「需要你决策」的通知加密推到你手机，看不到任何任务内容。
Free 够用吗？+
一个人跑一条流水线完全够。等你需要多线并行、无限岗位、用量分析时，再升级 Pro。
支持哪些系统？+
桌面端支持 macOS 与 Windows；配套手机 App 支持 iOS(含灵动岛实时活动)。
可以随时取消 / 导出数据吗？+
可以。按月订阅随时取消，数据一键导出，账号会话登出不会删除本地的流水线与运行记录。
