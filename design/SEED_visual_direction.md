# RunTeams 视觉方向种子（跨端设计系统 seed）

> 设计前的"方向种子"。全权由设计负责人（本会话）+ claude-design 定。
> 诊断：三端三套色、iOS 无品牌（纯系统默认）= "缺整体设计感"的根因。
> 决策：**不发明第四套，升级 web 的暖编辑室 DNA 为唯一跨端系统，三端继承。**

## 1. 一句话概念
**"你 AI 团队的安静作战室。"** 暖、编辑室气质、克制的高级感——认真的专业工具，
因为"健康=安静"而显得沉着。不玩闹、不冷酷公司风。

## 2. 北极星参照
- **Linear** —— 克制、密度、专业感；但我们要**暖**，不要它的冷。
- **Things 3 / iA Writer** —— 平静、手艺感、暖纸。
- **Vibe Kanban** —— 借鉴“列=岗位/阶段”的心智，手机上竖向呈现。
- 反面：一切蓝色通用 SaaS（含现 mockup 的 `#3b5bff`）——弃。

## 3. 调色板（升级 web 暖 DNA）
- **暖纸**：light `--bg:#f9f8f7` / `--panel:#ffffff`；dark `--bg:#1a1917` / `--panel:#232120`。
- **暖墨**：light `--ink:#282623` `--sub:#7a766e`；dark `--ink:#ece9e3` `--sub:#928d83`。
- **单色优先 accent = 墨本身**（`#282623` / `#ece9e3`）。**高级感来自克制**：装饰不用彩色。
- **彩色只留给"状态"**（唯一的彩色嗓门，因为它承载语义、才配得上颜色）：
  - 运行/等待 = 琥珀 `#a9760f`（dark `#d9a04a`）
  - 正常/完成 = 绿 `#3f7d4e`（dark `#4bc383`）
  - 阻塞/**需要你** = 红 `#bd4a3d`（dark `#ec7a70`）
- 暖发丝线 `#ecebe7`；柔阴影（web `--sh` 那套）。
- ⛔ 弃 iOS 的 systemBlue、弃 mockup 的蓝。

## 4. 字体
- UI：**Hanken Grotesk**（人文 grotesk，暖而认真）。
- **数字/ID/时间戳/状态：IBM Plex Mono** —— **签名动作**：一切定量状态（已试 8 · 交付 0 · 等待时长 · 重试次数）走等宽，传达"机器在替你干活的操作台"。

## 5. 性格 / 动效 / 情绪弧
- 平静、低动效、无弹跳。
- **"安静=健康"当状态设计**：健康首页刻意从容（留白、柔和、"一切正常"），
  彩色紧迫（琥珀/红）只在需要你时出现。
- 情绪弧 = 平静 → 一次清晰的告警 → 平静。

## 6. 密度
信息密但透气——**pro 工具密度**（对标 Zapier/Gumloop/Lindy，$29–49），非消费玩具的稀疏；但移动端间距优先。

## 7. 签名元素（跨端一致）
1. 等宽数字承载所有定量状态。
2. "团队=阶段/列"脊梁（手机竖向）。
3. 状态是唯一的颜色，其余单色。
4. 暖纸 + 柔阴影 + 暖发丝线。
5. **品牌标记：现有的"汇流箭头"（多线汇聚→箭头）保留**——寓意"多个员工→一条流"，已经不错。

## 8. 落地
- claude-design 建一套 design system（tokens 如上）→ hero 3 屏（首页两态/人工闸/竖向看板）锁语言 → 铺 app 其余屏 → desktop/web 继承同一 system（web 顺势从"半成品暖 DNA"升级到成品）。
- iOS 落地时 `DesignSystem.swift` 从"系统默认"改为继承本 tokens（这是 10 的活，非本阶段）。
